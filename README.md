# Publish — SANSTUDIOH Publishing App

Native Android/Jetpack Compose project prepared for Codemagic.

Package: `com.sanstudioh.publishing`

This is the clean app shell. It deliberately contains no fake production posts and does not pretend that the live WordPress/Core backend is connected.

Next implementation phases are the SANSTUDIOH Core API, authenticated publishing, media upload, WordPress publishing, contributor invitations, notifications, payments/earnings, rich inline editor, and release signing.

Build with:
`./gradlew assembleDebug`
or
`./gradlew assembleRelease`
